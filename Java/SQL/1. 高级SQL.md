# CTE Common Table Expression 公共表表达式

1. 当前查询的临时视图

```sql
    WITH customer_totals AS (
    SELECT
    CustomerID,
    SUM(Amount) AS total_sales
    FROM Orders
    GROUP BY CustomerID
    )
    SELECT *
    FROM customer_totals
    WHERE total_sales > 10000;
```

2. 定义多个CTE时用逗号分隔

```sql
WITH
first_cte AS (
SELECT ...
),
second_cte AS (
SELECT ...
),
third_cte AS (
SELECT ...
)
SELECT * FROM third_cte;
```
